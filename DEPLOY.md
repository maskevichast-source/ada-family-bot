# Инструкция: как всё заменить в Replit

Полный список: что создать, что заменить, что не трогать. Порядок ниже
не критичен (Python не запустится, пока не задеплоите ВСЁ разом, так что
можно менять файлы в любой последовательности, а потом перезапустить бота
один раз в конце).

---

## Шаг 1. Создать 5 новых файлов в `services/`

Этих файлов у вас ещё нет — создайте с нуля, скопировав содержимое из
приложенных файлов:

| Новый файл | Зачем нужен |
|---|---|
| `services/categories.py` | Единый список категорий трат/доходов — на него ссылаются почти все остальные файлы |
| `services/ai_config.py` | Имя модели DeepSeek в одном месте |
| `services/limits_ai.py` | Генерация лимитов через ИИ (было продублировано в двух местах — теперь один раз) |
| `services/money.py` | Разбор сумм — чинит баг «184,400 → 0» |
| `services/pending_receipts.py` | Хранилище «чек ждёт комментарий» — для двухшагового флоу |

## Шаг 2. Заменить содержимое существующих файлов в `services/`

Открываете файл в Replit → выделяете всё (Ctrl+A / Cmd+A) → вставляете
новое содержимое поверх:

- `services/charts.py`
- `services/deepseek_service.py`
- `services/sheets.py`
- `services/vision.py` ⚠️ **обновлён ещё раз только что** — забрал словарь
  банков и логику пополнений/переводов из вашего `openai_service.py`,
  берите самую свежую версию
- `services/memory.py` — по факту не менялся, но отдаю для сверки
- `services/timezone.py` — по факту не менялся, но отдаю для сверки
- `services/weather.py` — по факту не менялся, но отдаю для сверки

## Шаг 5. Что делать с `services/openai_service.py`

Он больше нигде не вызывается (я проверил — ни один из новых файлов его
не импортирует). Всё полезное из него (словарь банков, логика
пополнений/переводов) я перенёс в `vision.py`. Рекомендую **удалить** этот
файл — оставлять его без дела рискованно: если кто-то (или будущий ИИ)
случайно снова подключит его вместо `vision.py`, категории опять начнут
расходиться, как это уже один раз случилось. Но это ваш файл — решайте
сами, при желании можно просто оставить лежать неиспользуемым.

## Шаг 6. Что НЕ трогать

- `config.py` — там ваши настоящие ключи, только ДОБАВИТЬ одну строку
  (см. Шаг 7)
- `credentials.json` — ключ доступа к Google Sheets
- `bot.log`, `chat_history.json` — рабочие данные бота
- `services/__init__.py`, `handlers/__init__.py` — я их не видел и не
  менял
- `artifacts/`, `attached_assets/`, `lib/`, `scripts/` — не имеют
  отношения к правкам

## Шаг 7. Обязательное ручное действие — FAMILY_CHAT_ID

Причина, по которой напоминания и утренняя погода уходили в личку, а не
в группу: `VLAD_TELEGRAM_ID`/`DIANA_TELEGRAM_ID` — это ID **личных** чатов,
а не группы.

1. Задеплойте всё выше и перезапустите бота.
2. Напишите боту в группе «Семейный бюджет»: `/chatid`
3. Он ответит числом (обычно отрицательным для групп, например
   `-1001234567890`).
4. Откройте свой `config.py` и добавьте строку:
   ```python
   FAMILY_CHAT_ID = -1001234567890  # ваше число из шага 3
   ```
5. Перезапустите бота ещё раз.

Если пропустить этот шаг — бот продолжит слать проактивные сообщения в
личку (старое поведение), но теперь хотя бы явно предупредит об этом в
логах при каждом цикле.

## Шаг 8. Быстрая проверка после деплоя

- `/chatid` в группе → должен ответить ID
- Любой чек/скриншот БЕЗ подписи → должен спросить комментарий
- Тот же чек С подписью → должен записать сразу, без вопроса
- «сколько я потратил в этом месяце?» → сводка с цифрами и хотя бы одной
  фразой от ИИ ниже цифр
- «какие лимиты?» → список + комментарий с характером
- Скриншот пополнения Kaspi Gold с BCC → должен объяснить, что не пишет
  это в бюджет, а не сказать «не смогла распознать»
