# Ada Family Bot — patched build

Исправления в этой сборке:

- Реальное сохранение напоминаний с проверкой повторным чтением Reminders.
- Локальный парсер бытовых русских напоминаний: «сегодня в 9 вечера», «завтра в 9 утра», «в понедельник в 10».
- Диана больше не пишется как `D`: добавлена нормализация семейных имён по Telegram ID и алиасам.
- При старте выполняется мягкая санация старых строк `D` и `expense/income` в таблице.
- Google Sheets операции вынесены в `asyncio.to_thread`, чтобы не подвешивать Telegram event loop.
- Контекст Ады расширен до 50 последних сообщений и 200 последних операций.
- Промпт Ады обновлён: приватный семейный тон, меньше странных комментариев, больше контекста времени/выходных/поездок.
- Кнопки уточнения категорий показываются только при реальном сомнении.
- Чеки с несколькими позициями больше не теряют остальные позиции при уточнении.
- Погода упрощена: короткий прогноз, осадки, ветер и совет по одежде.
- Добавлен privacy middleware: бот отвечает только семейному чату или VLAD_TELEGRAM_ID/DIANA_TELEGRAM_ID.
- Сохранена текущая структура Google Sheets/PowerBI листов.
